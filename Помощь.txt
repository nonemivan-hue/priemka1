НАЗНАЧЕНИЕ
--------------------------------------------------------------------------------
Программа предназначена для оформления приёмки товаров, работ и услуг в ГКУ КК
УСЗН: ведение справочников, констант учреждения, формирование приказов
приемочной комиссии, документов «Приёмка» (акт ОКУД 0510452), печатных форм
и выгрузок в Excel, отчёта по объему принятых товаров, резервного копирования.

Запуск без браузера: двойной клик по Приемка_товаров.exe (или python desktop.py).
Интерфейс открывается в отдельном оконном приложении.

1. УСТАНОВКА И ЗАПУСК
================================================================================
См. файл INSTALL.md. Кратко:
  - Windows: запуск готового EXE (см. build_exe.bat) либо
      python -m venv venv && venv\Scripts\activate
      pip install -r requirements.txt
      python desktop.py
  - Первый запуск создаёт папку data/ с базой db.json.
  - Для сборки EXE: build_exe.bat (нужен PyInstaller).

2. КОНСТАНТЫ «УЧРЕЖДЕНИЕ» (меню: Константы)
================================================================================
Заполняются один раз при внедрении программы:
  • Учреждение (получатель), Обособленное подразделение, Структурное подразделение;
  • Главный администратор доходов бюджета (Учредитель);
  • Наименование бюджета, Валюта (наименование);
  • Адрес грузополучателя, Место поставки товара;
  • ИНН, ОГРН, КПП;
  • Адрес заказчика — заполняется по классификатору ФИАС (ИНДЕКС, Страна,
    Край/область, Район, Город/населенный пункт, ул., д. и т.д.);
  • Руководитель — выбирается из справочника «Сотрудники».

================================================================================
3. СПРАВОЧНИКИ (меню: Справочники)
================================================================================
• Поставщик          — реквизиты поставщика (адрес, ИНН, ОГРН, ИКЗ и др.).
                        Можно импортировать из Excel (пример: Поставщики.xlsx).
• Виды документов    — перечень документов об отгрузке (Акт, Накладная, УПД...).
• Номенклатура       — товары/работы/услуги: код товара, КРАТКОЕ наименование
                        (для отчета по объему), полное наименование, Страна
                        (из справочника «Страна происхождения»), Ед. изм. (из ОКЕИ),
                        Ставка НДС (из справочника «Ставки НДС»). Поля выбираются
                        из выпадающих списков. Импорт из Excel (Номенклатура.xlsx).
• Ставки НДС         — перечень ставок (без НДС, 5%, 7%, 10%, 20%...).
• Страна происхождения— цифровой код + наименование; кнопка «Загрузить из
                        Интернета» пополняет справочник автоматически.
• Адресный классификатор (ФИАС)— подгружается из сети Интернет (зеркала,
                        автопереключение источников); при отсутствии сети —
                        импорт файлом XML/CSV или работа из кэша.
• Ед. измерения (ОКЕИ)— единицы измерения, загружаются из Интернета.
• Сотрудники         — должность и ФИО; используются в приказах и руководителе.

Во всех справочниках есть: добавление, редактирование двойным щелчком,
ОДИНОЧНОЕ и МАССОВОЕ удаление (чекбоксы + «Выбрать все» + «Удалить выбранные»).

================================================================================
4. ДОКУМЕНТЫ
================================================================================
4.1. ПРИКАЗЫ КОМИССИИ (меню: Документы → Приказы комиссии)
     №, дата, наименование комиссии. Табличная часть: председатель (ФИО,
     должность) и члены комиссии (ФИО, должность) — из справочника «Сотрудники».
     Кнопки: «Печатная форма», «В Excel».

4.2. ПРИЕМКА (меню: Документы → Приемка)
     Заполняется в два шага:
     а) Реквизиты: №, дата акта (выбор из календаря), учреждение и подразделения
        (подставляются из констант), поставщик (при выборе подставляются адрес,
        ИНН, ОГРН, ИКЗ), документ-основание, основание приемки (вид/№/дата),
        ДОКУМЕНТ ОБ ОТГРУЗКЕ — выбирается из справочника «Виды документов»,
        ответственный сотрудник, приказ комиссии.
     б) РАЗДЕЛ 4 (таблица позиций): позиция выбирается из справочника
        «Номенклатура» раскрывающимся списком. При выборе АВТОМАТИЧЕСКИ
        заполняются и недоступны для правки: Код товара, Наименование,
        Краткое наименование, Страна происхождения (код+наим.), Ед. измерения
        (код ОКИ+наим.), Ставка НДС. Сотрудник вносит ТОЛЬКО Количество и Цену;
        суммы без НДС, сумма НДС и сумма с НДС считаются программой.
     Итоги документа рассчитываются автоматически.

4.3. ПЕЧАТНАЯ ФОРМА ПРИЕМКИ
     Кнопка «Печатная форма» формирует файл по унифицированной форме
     «Акт приемки товаров, работ, услуг» (ОКУД 0510452), формат А4 альбомный:
     раздел 1 (основной) + разделы 2–4 (остальное). Форма создается ПРОГРАММОЙ,
     БЕЗ ЖЁЛТЫХ ЗАЛИВОК полей. Идентификатор государственного контракта (ИКЗ)
     выгружается в ячейку CV29 листа «стр.1».
     В настольном режиме файл открывается в редакторе таблиц автоматически;
     в веб-режиме скачивается браузером.

4.4. ВЫГРУЗКА В EXCEL
     Кнопка «В Excel» сохраняет документ (реквизиты, позиции, итоги, подписи)
     в .xlsx формата А4 альбомный.
     • Настольный режим: программа ПРЕДЛАГАЕТ ВЫБРАТЬ ПУТЬ сохранения через
       диалог «Сохранить как…» (можно задать имя и папку). При отмене —
       сохранение в data/exports и автооткрытие.
     • Веб-режим: скачивание файла браузером.

================================================================================
5. ОТЧЕТ ПО ОБЪЕМУ ПРИНЯТЫХ ТОВАРОВ (меню: Отчеты)
================================================================================
Формируется по документам «Приемка». Фильтры: период (даты — из календаря),
поставщик. Группировка позиций — по КРАТКОМУ НАИМЕНОВАНИЮ номенклатуры
(при пустом — по полному); показывает объем (суммарное количество) и суммы
без НДС / НДС / с НДС. Кнопка «Выгрузить в XLSX» — отчет в Excel
(А4 альбомный, с итогами).

================================================================================
6. РЕЗЕРВНОЕ КОПИРОВАНИЕ И ВОССТАНОВЛЕНИЕ (меню: Резервные копии)
================================================================================
• Создать копию — вся база (константы, справочники, документы) в файл
  data/backups/backup_ГГГГММДД_ЧЧММСС_<комментарий>.json; можно скачать.
• Автокопия — при первом запуске каждого рабочего дня.
• Восстановить — из списка копий или из файла .json (флешка/диск); перед
  восстановлением автоматически создается страховочная копия текущего состояния.
• Хранится до 50 последних копий.

8. ЧАСТЫЕ ВОПРОСЫ
================================================================================
• «Сеть недоступна» при загрузке ФИАС — проверьте интернет; если сеть есть,
  программа сама переключается на резервный источник; при блокировке GitHub —
  импортируйте справочник файлом (XML/CSV) на странице справочника.
• Предупреждение openpyxl «Data Validation extension is not supported» —
  подавлено, данные из Excel читаются корректно.
• Изменить путь сохранения Excel — в окне «Сохранить как…».
• Перенос данных на другой компьютер — скопируйте папку data/ или используйте
  резервную копию (.json) и восстановление.
