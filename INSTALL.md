# Инструкция по установке и запуску
## Программа по приёмке товаров ГКУ КК УСЗН

---

## 1. Системные требования

| Компонент | Требование |
|---|---|
| Операционная система | Windows 7/10/11, Linux (ALT, Ubuntu), macOS |
| Python | версии **3.9** или выше (рекомендуется 3.11+) |
| Свободное место на диске | не менее 200 МБ |
| Доступ в Интернет | требуется для загрузки справочников (ФИАС, ОКЕИ, страны) и установки библиотек |
| Браузер | **не требуется** — программа запускается как настольное приложение (окно на рабочем столе). Браузер опционален только для сетевого режима работы нескольких пользователей |

Программа по умолчанию работает как **настольное приложение без браузера**: внутренний сервер поднимается в фоне, интерфейс открывается в отдельном окне (pywebview). Установки офисного пакета не требуется — печатные формы сохраняются в формате `.xlsx` (открываются в MS Excel, LibreOffice Calc или Р7-Офис).

## 2. Установка Python

### Windows
1. Скачайте установщик с сайта https://www.python.org/downloads/
2. При установке **обязательно отметьте галочку** «Add Python to PATH».
3. Проверка: откройте командную строку (`Win+R` → `cmd`) и выполните:
   ```
   python --version
   ```
   Должна отобразиться версия Python 3.9+.

### Linux (ALT / Ubuntu / Astra)
```bash
sudo apt-get install python3 python3-pip python3-venv
# для ALT Linux:
su - root && apt-get install python3-module-pip
```

## 3. Установка программы

### Шаг 1. Разместите файлы программы
Скопируйте папку с программой в любое удобное место, например:

- Windows: `C:\UssznReception\`
- Linux: `/opt/usszn-reception/`

Структура папки:
```
├── run.py                  # файл запуска
├── requirements.txt        # список зависимостей
├── app/                    # исходный код программы
│   ├── main.py             # веб-интерфейс (Flask)
│   ├── database.py         # хранилище данных (JSON)
│   ├── print_form.py       # печатная форма приёмки (openpyxl)
│   └── internet_loaders.py # загрузка справочников из интернета
├── data/
│   └── db.json             # база данных программы (создаётся автоматически)
├── Поставщики.xlsx          # примеры справочников для импорта
├── Номенклатура.xlsx
├── Раздел1.xlsx
└── Остальное.xlsx
```

### Шаг 2. Создайте виртуальное окружение (рекомендуется)

**Windows (командная строка):**
```bat
cd C:\UssznReception
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**
```bash
cd /opt/usszn-reception
python3 -m venv venv
source venv/bin/activate
```

### Шаг 3. Установите зависимости
```
pip install -r requirements.txt
```

Будут установлены библиотеки:
- **Flask** ≥ 3.0 — внутренний сервер интерфейса программы;
- **pywebview** ≥ 4.4 — настольный режим: окно приложения без браузера;
- **openpyxl** ≥ 3.1 — чтение/запись Excel (импорт справочников и печать форм).

> Если установка через pip в офисе заблокирована политикой безопасности, скачайте пакеты на машине с доступом в Интернет командой
> `pip download flask openpyxl pywebview -d packages\`
> и перенесите папку `packages` на рабочий компьютер флешкой. Установка офлайн:
> `pip install --no-index --find-links=packages flask openpyxl pywebview`

## 4. Запуск программы (без браузера)

```
python run.py
```

Программа запустится как **настольное приложение**: откроется собственное окно
«Приёмка товаров — ГКУ КК УСЗН». Браузер не открывается и не требуется.
Закрытие окна закрывает и программу. То же самое можно выполнить командой
`python desktop.py`.

Печатная форма приёмки в настольном режиме формируется в файл
`data\exports\Приемка_<№>.xlsx` и автоматически открывается в редакторе таблиц
(MS Excel / LibreOffice / Р7-Офис) — без скачивания через браузер.

### Сетевой режим (работа нескольких пользователей, опционально)

```
python run.py --server
```

Поднимается сервер на порту 5000; пользователи сети открывают
`http://IP-адрес-сервера:5000` в браузере. При необходимости откройте порт
5000 в брандмауэре. Остановка: `Ctrl+C` в окне консоли.

### Сборка автономного EXE (без Python и без браузера, Windows)

```
pip install pyinstaller
build_exe.bat
```

В папке `dist` появится файл `Приемка_товаров.exe` — программа целиком
(сервер + окно приложения) в одном исполняемом файле, запускается двойным
щелчком.

### Автозапуск при старте Windows (по желанию)
Создайте файл `start.bat`:
```bat
@echo off
cd /d C:\UssznReception
call venv\Scripts\activate
python run.py
pause
```
и поместите ярлык на него в папку «Автозагрузка» (`shell:startup`).

### Автозапуск как служба Linux (по желанию)
Файл `/etc/systemd/system/usszn.service`:
```ini
[Unit]
Description=UsSZN Reception
After=network.target

[Service]
WorkingDirectory=/opt/usszn-reception
ExecStart=/opt/usszn-reception/venv/bin/python run.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable usszn && sudo systemctl start usszn
```

## 5. Первичная настройка после запуска

1. **Константы → «Учреждение»** — заполните реквизиты: наименование получателя, обособленное/структурное подразделение, ГРБС (учредитель), наименование бюджета, валюта, ИНН/КПП/ОГРН, адрес грузополучателя, адрес заказчика и место поставки (заполняются из справочника «Адресный классификатор (ФИАС)»), руководитель (из справочника «Сотрудники»).
2. **Справочники**:
   - **Поставщик**, **Номенклатура** — можно заполнить вручную или импортировать из файлов `Поставщики.xlsx` и `Номенклатура.xlsx` (кнопка «Импорт из Excel»);
   - **Страна происхождения**, **Ед. измерения**, **Адресный классификатор (ФИАС)** — нажмите «Загрузить из интернета» (потребуется доступ к сети; данные берутся с официальных источников — okspo.fsbu.ru, ФИАС/nalog.ru);
   - **Виды документов**, **Ставки НДС**, **Сотрудники** — заполните вручную.
   В справочнике **«Номенклатура»** поля подбираются из связанных справочников: «Страна» — из «Страна происхождения», «Ед. изм.» — из «Ед. измерения (ОКЕИ)», «Ставка НДС» — из «Ставки НДС» (выпадающие списки; при выборе автоматически заполняются наименование страны и обозначение единицы измерения).
   Во **всех справочниках** доступно массовое удаление: отметьте записи галочками (или «Выбрать все» в заголовке таблицы) и нажмите «🗑 Удалить выбранные».
3. **Документы**: создайте «Приказ комиссии» (председатель и члены — из справочника «Сотрудники»), затем документ «Приёмка».
   В приёмке **раздел 4** заполняется из справочника «Номенклатура»: при выборе номенклатуры автоматически подставляются код товара, наименование, страна происхождения, ед. измерения и ставка НДС (поля недоступны для ручного ввода) — сотрудник вносит только **количество** и **цену**. Поле «Документ об отгрузке» выбирается из справочника «Виды документов». В номенклатуре предусмотрено поле «Краткое наименование» — оно переносится в позицию и используется в отчёте по объёму принятых товаров.
4. **Печатная форма приёмки** — кнопка «🖨 Печатная форма»: файл формируется по шаблону «Приложение к распоряжению ректора № 3 от 22.01.2024г.», формат А4, альбомная ориентация, состоит из разделов «Основной раздел» и «Остальное».
5. **Выгрузка документов в Excel** — кнопка «📤 В Excel» в списках и карточках документов «Приёмка» и «Приказы комиссии»: формирует .xlsx (А4, альбомная) с реквизитами, таблицей позиций/состава комиссии, итогами и подписями. В веб-режиме файл скачивается; в настольном режиме сохраняется в `data/exports` (Приемка_Excel_<№>.xlsx, Приказ_<№>.xlsx) и открывается в редакторе таблиц.
6. **Отчёт по объёму принятых товаров** — меню «Отчёты»: группировка позиций всех приёмок по номенклатуре за период, суммы и выгрузка в XLSX.
5. **Отчёты → «Отчёт по объёму принятых товаров»** (меню «Отчёты» или адрес `/otchet/obem`) — формирует объём принятых товаров (количество в единицах измерения) и суммы без НДС / НДС / с НДС по позициям номенклатуры на основании всех документов «Приёмка». Доступны фильтры по периоду (даты приёмок) и поставщику; кнопка «Выгрузить в XLSX» сохраняет отчёт в папку `data/exports/` (в настольном режиме файл сразу открывается в редакторе таблиц).

## 6. Резервное копирование и восстановление данных

Все данные хранятся в файле **`data/db.json`**. В программе есть специальное окно
**💾 Резервные копии** (пункт меню сверху или адрес `/backup`):

- **«💾 Создать копию»** — снимок всей базы (константы, справочники, документы) с необязательным комментарием; копия сохраняется в `data/backups/`, в веб-режиме предлагается дополнительно скачать файл;
- **автоматическая копия** создаётся при первом запуске программы каждый рабочий день;
- **«♻️ Восстановить»** из выбранной копии списка (дата, версия программы, состав базы, размер); перед каждым восстановлением автоматически создаётся страховочная копия текущего состояния;
- **«📂 Восстановить из файла»** — загрузка копии `.json` с флешки или сетевого диска (проверка структуры файла);
- **«⬇ Скачать»** и **«Удалить»** — управление файлами копий.

Хранится не более 50 последних копий (старые удаляются автоматически). Копии можно переносить между компьютерами: скопируйте файл `backup_*.json` и восстановите через «📂 Восстановить из файла».

## 7. Возможные проблемы

| Симптом | Решение |
|---|---|
| `python: команда не найдена` (Windows) | Не добавлен Python в PATH — переустановите с галочкой «Add Python to PATH» |
| `error: externally-managed-environment` (Linux) | Используйте виртуальное окружение (шаг 3.2) |
| Порт 5000 занят | Измените порт в файле `run.py` (`port=5000` → другой) |
| Справочники из интернета не загружаются | Проверьте доступ в Интернет и настройки прокси учреждения; справочники можно завести вручную |
| Не открывается печатная форма | Убедитесь, что файлы шаблонов `Раздел1.xlsx`, `Остальное.xlsx` находятся в папке программы |

## 7.1. Версии программы

Текущая версия указана в файле **`version.py`** (единый источник версии), отображается в шапке и подвале интерфейса,
в заголовке окна настольного приложения и на странице **«О программе / история версий»** (`/about`).
История изменений ведётся в файле **`CHANGELOG.md`**. При сборке EXE (`build_exe.bat`) версия записывается
в свойства файла Windows (файл `version_info.txt`).

Для выпуска новой версии: измените `APP_VERSION` в `version.py`, добавьте запись в `CHANGELOG.md`
и при необходимости обновите номер в `version_info.txt`.

### Выгрузка в Excel с выбором папки

В настольном режиме (запуск `python desktop.py` или EXE) при нажатии кнопки «В Excel»
появляется окно **«Сохранить как…»** — укажите нужную папку и имя файла. Если диалог
отменён, файл сохранится в `data/exports/` программы. В сетевом (веб) режиме файл
скачивается через браузер в папку загрузок.

### Печатная форма

Форма ОКУД 0510452 заполняется программой полностью: без жёлтых заливок,
с выгрузкой идентификатора госконтракта (ИКЗ) в ячейку CV29 листа «стр.1».
