# История версий

Версия программы указана в файле `version.py` и отображается в шапке, подвале интерфейса и на странице «О программе» (`/about`).

## 1.7.1 (27.10.2026)
- **Печатная форма: удалены лишние данные из ячеек** — в формируемом акте (ОКУД 0510452) очищаются ячейки листа «стр.1»: FF1, FJ1, FF2, FL2 (остатки примеров «Усл», наименование товара, «Дата» и дата из файла-шаблона), а также ячейка FK2 (дата в правом верхнем углу) листа «стр.2_3». Программа больше не записывает в них значения; очистка выполняется после заполнения формы, поэтому данные не попадают в готовый файл даже если присутствуют в шаблонах Раздел1.xlsx / Остальное.xlsx.

## 1.7.0 (27.10.2026)
- **Печатная форма без жёлтых заливок**: из формирования акта (ОКУД 0510452) исключена жёлтая подсветка заполняемых полей — данные вносятся программой целиком, выделение «для заполнения» из файлов-примеров больше не применяется.
- **ИКЗ выгружается корректно**: реквизит «Идентификатор государственного контракта, договора» (поле `ikz` документа «Приёмка») записывается в ячейку CV29 печатной формы; при выборе поставщика ИКЗ автоподставляется из справочника «Поставщик».
- **Выгрузка в Excel с выбором пути**: в настольном режиме кнопка «В Excel» открывает стандартный диалог «Сохранить как…» (при отмене — сохранение в папку программы data/exports); в веб-режиме — скачивание файла.
- **Поля «Дата» — выбор из календаря**: во всех документах (приёмка, приказ комиссии) и фильтрах отчёта используются нативные календари (`input type=date`) с хранением формата дд.мм.гггг в базе.

## 1.5.0 (27.10.2026)
- **Справочник «Номенклатура»: добавлено поле «Краткое наименование»** — используется для группировки и вывода в отчёте по объёму принятых товаров; заполняется вручную в таблице справочника или импортируется из Excel (колонка после «Код товара»).
- **Отчёт по объёму принятых товаров**: позиции группируются по краткому наименованию (при его отсутствии — по полному); таблица и XLSX-выгрузка содержат столбцы «Краткое наименование» и «Наименование» (полное описание).
- При выборе номенклатуры в документе «Приёмка» краткое наименование автоматически переносится в позицию документа и попадает в печатную форму и выгрузку Excel.

## 1.4.0 (27.10.2026)
- **Массовое удаление записей во всех справочниках**: чекбоксы в каждой строке таблицы + «Выбрать все» в заголовке, кнопка «🗑 Удалить выбранные (N)» с подтверждением; серверный маршрут `/catalog/<name>/delete` принимает список индексов `indexes` (одиночное удаление `_index` обратно совместимо), отвечает числом удалённых записей.
- **Справочник «Номенклатура»: поля подбираются из связанных справочников** — «Страна» из «Страна происхождения», «Ед. изм.» из «Ед. измерения (ОКЕИ)», «Ставка НДС» из «Ставки НДС» (выпадающие списки; при выборе автоматически заполняются наименование страны и обозначение единицы измерения; значения сверяются с источниками и на сервере при сохранении).

## 1.3.1 (27.10.2026)
- **Исправлена загрузка справочника ФИАС из интернета**: заменён недоступный источник (открытый датасет open-fias отдавал 404 — программа ошибочно сообщала «сеть недоступна»); подключены проверенные открытые данные ФИАС/ГАР: субъекты РФ и населённые пункты/районы (два зеркала каждое: raw.githubusercontent.com и cdn.jsdelivr.net), всего до ~2400 адресов; при недоступности одного источника программа автоматически пробует следующий.
- Теперь при реальной недоступности сети в сообщении указывается причина по каждому источнику; данные берутся из кэша предыдущей загрузки (`data/cache_fias.json`), а при его отсутствии — из встроенного минимума с подсказкой импортировать полный ФИАС файлом XML/CSV.

## 1.3.0 (27.10.2026)
- **Резервное копирование и восстановление данных**: окно «💾 Резервные копии» (`/backup`) — создание копий с комментарием, список копий (дата, версия программы, состав базы, размер), восстановление из выбранной копии или загруженного файла `.json`, удаление копий; страховочная копия перед каждым восстановлением; автоматическая копия при первом запуске за день; хранение — `data/backups/`.
- **Версии программы**: файл `version.py` (единый источник версии), отображение версии в шапке/подвале, страница «О программе / история версий» (`/about`), файл CHANGELOG.md.

## 1.2.0 (27.10.2026)
- Возврат из печатной формы: глобальная кнопка «← Назад» (cookie `_back` + заголовок `X-Back`), кнопки возврата в карточках приёмки и приказа.
- Исправление ошибки печати `'MergedCell' object attribute 'value' is read-only` (формирование формы при любом количестве позиций).
- Устранено предупреждение openpyxl «Data Validation extension is not supported» при импорте Excel.

## 1.1.0 (27.10.2026)
- Выгрузка документов «Приёмка» и «Приказ комиссии» в Excel (кнопка «📤 В Excel», А4 альбомная, реквизиты, позиции, итоги, подписи).
- Отчёт по объёму принятых товаров с фильтрами (период, поставщик) и выгрузкой в XLSX.
- Приёмка: раздел 4 заполняется из справочника «Номенклатура» (код товара, страна происхождения, ед. измерения, ставка НДС подставляются автоматически; сотрудник вносит только количество и цену); «Документ об отгрузке» выбирается из справочника «Виды документов».

## 1.0.0 (27.10.2026)
- Настольный режим работы без браузера (`desktop.py`, pywebview): печать и выгрузка сохраняются в `data/exports/` и открываются в редакторе таблиц.
- Базовая реализация: константы «Учреждение» (с адресами ФИАС), 8 справочников (импорт из Excel, автозагрузка стран/ОКЕИ/ФИАС из интернета), документы «Приказы комиссии» и «Приемка», печатная форма «Приложение к распоряжению ректора № 3 от 22.01.2024г.» (А4, альбомная).
