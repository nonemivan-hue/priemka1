# История версий

## 1.8.3 (2026-10-29)
### Новое: перезаполнение полей основания при смене поставщика в приёмке
- В документе «Приемка» при выборе (смене) поставщика автоматически
  перезаполняются поля из справочника «Поставщики»: № основания
  (контракт/договор), Дата основания и Идентификатор госконтракта (ИКЗ).
- Если у нового поставщика соответствующих данных нет — поля очищаются.
- Сохранённые/введённые вручную значения при открытии документа не
  затираются: автоподстановка дозаполняет только пустые поля; принудительное
  перезаполнение выполняется именно при смене поставщика.

## 1.8.2 (2026-10-28)
### Новое: выбор IP-адреса и порта веб-сервера перед запуском
- При запуске программы (python run.py / python desktop.py / EXE) теперь
  запрашиваются параметры внутреннего веб-сервера: IP-адрес и порт.
- В консоли — текстовый запрос (Enter — значения по умолчанию:
  127.0.0.1, порт 8765 для настольного режима; 0.0.0.0:5000 для --server).
  В EXE без консоли — оконный диалог выбора (tkinter); при отмене — по
  умолчанию. Если консоль и tkinter недоступны — используются значения
  по умолчанию (запуск не блокируется).
- Адрес 0.0.0.0 открывает доступ к приложению из локальной сети по IP
  компьютера; 127.0.0.1 — только с этого компьютера.
- Параметры можно задать аргументами командной строки без запроса:
  --host <IP> (или --ip <IP>) и --port <N>, а также в форме --host=<IP>,
  --port=<N>. Некорректный порт (вне 1..65535) заменяется значением
  по умолчанию с предупреждением.

## 1.8.1 (2026-10-28)
### Новое: автоматическая нумерация документов приёмки в рамках года
- Документ «Приемка»: номер акта подставляется автоматически — следующий
  целочисленный номер за год даты документа (max(номер)+1; для нового года —
  с единицы). Пользователь может изменить номер вручную — введённое значение
  сохраняется как есть и больше не перезаписывается.
- В форме создания приёмак поля «№ акта» и «Дата акта» заполняются сразу
  (автонимер + сегодняшняя дата); при смене даты в ещё не тронутом вручную
  документе номер пересчитывается (маршрут /dokument/priemka/next_nomer).
- При сохранении документа с пустым номером/«б/н» автонумерация применяется
  на сервере; пустая дата акта заполняется сегодняшним числом.

## 1.8.0 (2026-10-28)
### Новое: выгрузка в Word и флаг «Не действующий приказ»
- Документ «Приемка»: добавлена кнопка «📝 Word» — выгрузка акта приёмки в формате
  .docx по образцу «Акт приемки оказанных услуг, результатов отдельного этапа
  исполнения контракта». Новый модуль app/print_form_word.py, маршрут
  /dokument/priemka/<id>/word; в настольном режиме предлагается путь сохранения
  и файл открывается в редакторе, в веб-режиме — скачивание браузером.
- Приказы: чекбокс «Не действующий приказ» в форме приказа. Такие приказы
  отображаются в списке с пометкой «не действующий» (серым), но НЕ попадают
  в выпадающий список выбора приказа в документе «Приемка» (выбрать их нельзя;
  ранее связанный с документом приказ остаётся видимым для сохранения данных).

## 1.7.7 (2026-10-28)
### Новое: отчёт «Количество номенклатуры за период по поставщикам»
- Новый раздел меню и карточка на главной: /otchet/nomenklatura — по каждому поставщику
  (или по документу приёмки) считается количество позиций номенклатуры за выбранный
  период, выводятся наименования и суммы без НДС; уникальная номенклатура определяется
  по коду товара (при отсутствии — по наименованию).
- Фильтры: период (с даты по дату), поставщик, разрез отчёта (по документам / по поставщикам
  сводно). Выгрузка в XLSX с итоговыми строками; в настольном режиме файл открывается
  в редакторе таблиц.

## 1.7.6 (2026-10-28)
### Исправление: пустой экран при печати
- Печатная форма и Акт 61н больше никогда не показывают пустой экран без кнопки возврата:
  при любой ошибке (документ не найден, нет шаблонов, сбой формирования) выводится
  понятная страница с текстом ошибки и кнопками «На главную» и «← Назад».
- Добавлены глобальные обработчики 404/500 — любая ошибка ведёт на страницу с возвратом.
- JS-функции prt/prt61 (главная, список приёмок, карточка): ответ ошибки обрабатывается
  корректно, предусмотрена автоматическая страховка возврата на главную; сообщение об
  ошибке показывается в диалоге, а не «тихим» переходом.
- JSON-ответы печати в настольном режиме помечены no-store и не участвуют в механике
  кнопки «Назад» (cookie предыдущей страницы не перезаписывается).
