# Программа по приемки товаров в ГКУ КК УСЗН

📄 **Инструкция по установке и запуску — см. файл [INSTALL.md](INSTALL.md)**

Программа состоит из справочников и документов и констант
Константы:
Учреждение, состоит из Учреждение (получатель), Обособленное подразделение, Структурное подразделение, Главный администратор доходов бюджета (Учредитель), Наименование бюджета, Валюта (наименование), Адрес грузополучателя, ИНН, ОГРН, КПП, Адрес заказчика (Заполняется из справочника ФИАС,состоит из: ИНДЕКС, Страна, Край/область, Район, Город, населенный пункт, ул., д. и тд.),Место поставки товара, выполнения работы, оказания услуги аналогично Адрес заказчика, Руководитель (данные беруться из справочника Сотрудники)

Справочники:
	Поставщик - пример справочника файл Поставщики.xlsx
	Вид документов: состоит из вида документов
	Номенклатура - пример справочника файл Номенклатура.xlsx
	Ставки НДС - состоит из Ставки НДС
	Страна происхождения: состоит из цифрового кода и Наименования страны (справочник можно загрузить из интернета, программа сам ищет в интернете данный справочник и подгружает значения в него)
	Адресный класификатор - данные в справочник подгружаются из класификатора ФИАС из сети интернет для дальнейшего использования в программе
	Ед.измерения - Справочник загружается едениц измерений подгружается из сети Интерент 
	Сотрудники: состоит из должности и ФИО сотрудника

Документы:
	1. Приказы коммисии: 
		№, дата, наименование коммисии
			Табличная часть:
				Председатель коммисии, фио, должность (беруться из справочника сотрудники)
				Члены коммисии ФИО, должность (беруться из справочника сотрудники)
	2. Приемка (печатная форма "Приложение к распоряжению ректора № 3 от 22.01.2024г."  формат А4 ландшафт) 
		состоит из 2 частей:
		1. Основной раздел: (Раздел1.xlsx: желтым выделенны поля для заполнения)
		2. остальное : (Остальное.xlsx: желтым выделенны поля для заполнения)
		Раздел 4 заполняется из справочника «Номенклатура»: при выборе номенклатуры автоматически заполняются Код товара, Страна происхождения, ед. изм., ставка НДС; сотрудник вносит только количество и цену. Поле «Краткое наименование» номенклатуры используется в отчёте по объёму принятых товаров.
		Документ об отгрузке выбирается из справочника «Виды документов».

Отчёты:
		Отчет по объему принятых товаров — формируется по документам «Приемка»:
		группировка позиций по номенклатуре, объем (количество в ед. изм.),
		суммы без НДС / НДС / с НДС; фильтры по периоду и поставщику,
		выгрузка в XLSX (адрес /otchet/obem).

## Резервные копии и версии

- Окно **Резервное копирование и восстановление** (`/backup`): создание копий базы с комментарием, автоснятие копии при первом запуске за день, восстановление из списка или загруженного файла `.json`, скачивание и удаление копий; перед каждым восстановлением создаётся страховочная копия. Хранилище — `data/backups/`.
- Версия программы — в `version.py`; отображается в шапке/подвале, в заголовке окна и на странице «О программе» (`/about`); история изменений — `CHANGELOG.md`.

## Выгрузка документов в Excel

- В документах «Приёмка» и «Приказ комиссии» кнопка **«📤 В Excel»** формирует .xlsx с реквизитами, таблицами позиций/членов комиссии и итогами (формат А4, альбомная).
- **Веб-режим**: файл скачивается браузером. **Настольный режим (без браузера)**: открывается стандартный диалог **«Сохранить как…»** — сотрудник выбирает путь и имя файла; при отмене документ сохраняется в папку программы `data/exports/` и автоматически открывается в редакторе таблиц.

## Поля «Дата»

Во всех документах и фильтрах отчётов даты выбираются из **встроенного календаря** (нативный виджет); в базе данных хранится формат дд.мм.гггг.

## Печатная форма

Печатная форма приёмки формируется программой по унифицированной форме ОКУД 0510452; жёлтая подсветка полей из файлов-примеров не применяется, ИКЗ (идентификатор государственного контракта) выгружается в соответствующую ячейку формы.
